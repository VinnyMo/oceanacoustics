# Contributing

Submit an issue or pull request to the public repository. For a scientific observation include site, UTC, archive ID and version, byte range, algorithm revision, uncertainty and reproduction steps. Link permissible source evidence. Exclude bulk audio, private storage locations, tokens and access logs. Document third-party attribution and redistribution rights.

For a code change run the offline tests, compare against the current benchmark, and explain changes to storage, coverage and existing evidence. Detector changes need an algorithm version and a separate experiment state or explicit migration. Describe negative findings. Research review and operational changes take place outside the public website.

Software contributions use GPL-3.0-only. Original research outputs use CC BY 4.0 where the contributor holds those rights.
